# ============================================
# Installation Instructions
# ============================================
# 1. Install Python 3.9+ with pip
# 2. Install dependencies:
#    pip install -r requirements.txt
#
# For Phase 2, also set your Groq API key:
#    export GROQ_API_KEY="your-api-key"
#
# For YouTube downloads you also need:
# 1. Node.js (or Deno) - JS runtime for yt-dlp's challenge solver
#    https://nodejs.org/
# 2. The local PO Token server (auto-started by the app, but you can build it
#    manually with):
#      cd tools/bgutil-server && npm install && npx tsc
#      node build/main.js --port 4416
# 3. cookies.txt - export your logged-in YouTube cookies (Netscape format)
#    into the project root. Required to get past YouTube's bot-check.
#
# For faster-whisper, install one of:
#    - CPU: pip install torch --index-url https://download.pytorch.org/whl/cpu
#    - CUDA 11.8: pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
#
# For Phase 4 (YouTube Upload), you need:
# 1. Google Cloud Project with YouTube Data API v3 enabled
# 2. OAuth 2.0 Client ID credentials downloaded as client_secrets.json
#    - Go to: https://console.cloud.google.com/apis/credentials
#    - Create "Desktop" application type OAuth client
#    - Download JSON and rename to client_secrets.json
#
# Model files will be downloaded automatically on first use:
#   - tiny: ~75MB
#   - small: ~1.2GB
#   - medium: ~2.5GB
#   - large-v3: ~3.5GB
